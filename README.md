# 水果塔防 Unity 迁移版

这是 `E:\project\webapp\furitDefense` 的 Unity 原生迁移工程，目标编辑器版本为 **Unity 6000.3.19f1（Unity 6.3 LTS）**。

## 当前可玩范围

- 15 波僵尸、生命/阳光/胜负、波间倒计时、暂停与 1/2 倍速。
- 五种水果、刷新栏、随机五选、花盆种植、移动、二合一升星。
- 豌豆单体、西瓜范围、香蕉穿透、榴莲近战范围、向日葵产阳光。
- 第 3/6/9/12 波武器与花盆奖励；机枪、冰块、辣椒效果与花盆相邻扩建。
- 1600×900 自适应界面，保留 Web 版矩形路线、左战场/右构筑区。
- 完整拖拽会话：8 像素启动阈值、按拖拽图标矩形碰撞而非鼠标点命中、按重叠面积选目标、目标吸附、绿色可放置、金色可合成、红色非法、松手提交、取消返回提示。
- 水果可在刷新栏、花盆之间拖动和合成；武器可拖到水果；花盆可拖到绿色扩建格。点击操作继续作为无障碍辅助入口。
- 已接入原创临时美术图集，水果、僵尸、武器及花盆均有对应图标；花盆明确区分空盆、已种植、可扩建和锁定状态。
- 全部 48 个种植格常驻显示；初始 8 个花盆覆盖在对应格上，选择花盆工具时再叠加可扩建/不可扩建提示。
- 刷新栏允许直接覆盖已有水果；旧水果携带的武器会退回库存。非保底结果有 10% 概率刷出花盆，花盆自动入库并在结果槽短暂显示。
- 攻击动作按 Web 版分阶段结算：豌豆追踪弹、西瓜 0.4 秒抛物线落点爆炸、香蕉 1.5 倍射程往返穿透、榴莲落砸范围震击、向日葵产阳光脉冲。
- 武器动作已区分：机枪四连发且间隔 0.2 秒，冰块命中减速/五次冻结并支持冰向日葵开场减速，辣椒叠加三层燃烧并强化向日葵产量。

## 操作

1. 点击“刷新五株水果”。
2. 将刷新栏里的水果拖到花盆种下；也可以先点击水果，再点击花盆。
3. 拖动已种水果到空花盆进行移动，拖到同种同星水果进行合成；也可拖回刷新栏。
4. 将武器拖到水果安装；将花盆拖到绿色候选格扩建。松手未命中时物品返回原位。
5. 点击“开始下一波”。空格暂停，数字键 `1`/`2` 切换速度。

## 工程结构

- `Assets/Scripts/Core`：无场景依赖的规则、状态与配置。
- `Assets/Scripts/Core/DragGeometry.cs`：拖拽预览矩形、重叠面积和最佳目标选择。
- `Assets/Scripts/FruitDefenseGame.cs`：首版原生 Unity 表现层和输入。
- `Assets/Resources/TempArt/fruit-defense-temp-atlas.png`：运行时临时美术图集。
- `Assets/Resources/TempArt/combat-vfx-atlas.png`：弹体、爆炸、震波、冰冻、燃烧和阳光等临时攻击特效图集。
- `Assets/Editor/ProjectSetup.cs`：场景/构建设置生成与迁移烟测。
- `Assets/Scenes/Main.unity`：唯一启动场景（由配置脚本生成）。
