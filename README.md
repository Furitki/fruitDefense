# 水果塔防

一个基于 React、TypeScript 和 Vite 的单机 Web 塔防原型。刷新随机植物、拖拽布阵与二合升级，使用武器和花盆扩建抵御 15 波僵尸。

## 运行

```powershell
npm install
npm run dev
```

默认开发地址由 Vite 输出。生产验证：

```powershell
npm run typecheck
npm test
npm run build
```

## 部署

部署到默认服务器的 `/root/app/furitDefense`，并在 `3000` 端口启动：

```powershell
.\deploy.ps1
```

脚本会先执行类型检查、测试和生产构建，再使用本机 `~/.ssh/id_ed25519` 密钥自动上传并切换服务，无需输入服务器密码。

## 操作

- 点击“刷新植物”消耗阳光获得五株植物；苗圃清空前不能再刷新。
- 将苗圃植物拖到花盆，或先点击植物再点击目标花盆。
- 将同种类、同星级植物拖到一起进行二合升级，最高四星。
- 场上植物可以移动到空花盆；战斗中移动有两秒冷却。
- 将植物拖入出售区，或在植物信息中点击出售。
- 第 3、6、9、12 波获得机枪、冰块、辣椒和花盆奖励。
- 选择/拖动武器到植物完成安装；出售装备植物会回收武器。
- 选择花盆道具后点击绿色正交相邻候选格完成永久扩建。
- 支持暂停和一倍/二倍速度。

## 实现范围

- 五种植物：豌豆、西瓜、香蕉、榴莲、向日葵。
- 四类僵尸：普通、快速、装甲、精英。
- 15 波、核心生命、胜利/失败与重新开始。
- 单体弹道、范围爆炸、往返穿透、近战范围和经济生产。
- 机枪攻速修正、冰减速/冻结、辣椒燃烧叠层及向日葵转换效果。
- 植物范围、香蕉方向、空花盆覆盖和扩建候选预览。
- 鼠标拖拽、触摸 pointer 操作、点击替代路径和键盘可访问控件。
