## Context

战斗运行在 foundation 提供的统一时钟和归一化战场中。道路为环绕果园核心的单条闭合视觉路径，但入口和出口是不同路径端点；敌人统一替换为僵尸主题。

## Goals / Non-Goals

**Goals:**

- 完成 15 波具有增长压力的自动战斗与胜负闭环。
- 让五种植物的射程、站位和攻击形态能够从视觉和结果上区分。
- 为武器模块预留命中状态修正入口。

**Non-Goals:**

- 僵尸不攻击植物，植物没有生命值。
- 不实现分叉路线、空中单位或复杂物理碰撞。

## Decisions

1. 路径表示为有序坐标点，僵尸保存 `progress` 并按累计长度采样位置；相比 DOM 路径动画，这允许暂停、减速和测试一致。
2. 每一帧先推进状态效果与移动，再执行生产/攻击，最后结算伤害、死亡、漏怪和波次，保证事件顺序固定。
3. 索敌按照剩余路径最短、生命较低、生成序号较早排序，直接实现需求中的核心优先规则。
4. 豌豆使用追踪目标投射物；西瓜保存落点；香蕉保存固定方向和往返阶段；榴莲直接执行半径判定；向日葵走经济 tick。
5. 波次由配置表生成，普通、快速、装甲和精英只改变生命、速度和奖励，不引入额外技能。

## Risks / Trade-offs

- [西瓜短延迟仍可能砸空] → 飞行时间限制为 0.4 秒，并在落点显示预警。
- [香蕉几何命中过于严格] → 使用线段到点距离加僵尸半径判断。
- [15 波测试耗时] → 提供二倍速和测试用纯函数推进。
