# 5.11 localhost cache-coherence acceptance

Status: **pass**.

The stable `deploy/server.mjs` previously cached a SHA-256 value forever by file
path. An in-place WebGL rebuild could therefore leave `index.html` with a stale
ETag and let an ordinary reload reuse the previous fixed-size host even though
the current file bytes had changed.

The content-hash cache now keys each entry by current file size and modification
time. `scripts/check-webgl-server-etag.mjs` starts an isolated server, fetches a
fixture, replaces that fixture at the same path, and sends the old
`If-None-Match`. The gate requires a `200` response, a different ETag, and the
replacement body. It passed with marker `WEBGL_SERVER_ETAG_OK`.

The user-facing port 4173 service was restarted on the updated server code and
verified without a query-string cache buster at a 1280 by 720 browser viewport:

- host marker: `portrait-contain-v1`;
- canvas rectangle: `(474.4125, 0, 331.1625, 720)`;
- complete canvas bounds: right `805.575`, bottom `720`;
- document client and scroll dimensions: `1280 by 720`;
- layout: `desktop-contain`;
- no vertical or horizontal scroll dependency.

This check covers the local ordinary-WebGL review service only.
