# Fruit Defense UI font

`NotoSansSC-UI.ttf` is a project-specific regular-weight subset of Google Fonts' Noto Sans SC variable font. Noto Sans SC is distributed under the SIL Open Font License 1.1; the repository copy of that license is `OFL-NotoSansSC.txt`.

Source: https://github.com/google/fonts/tree/main/ofl/notosanssc

The subset was generated with fontTools 4.63.0 from the visible characters found under `Assets/Scripts`, printable ASCII, and the UI symbols `★♥☀♣×·✓`.

Size record for the 2026-07-14 portrait WebGL build:

- Upstream variable font: 17,772,300 bytes
- Unity font subset: 145,828 bytes, retaining all 355 prior cmap entries and adding 10 current UI code points
- `WebGL.data.gz` before bundled font: 4,734,577 bytes
- `WebGL.data.gz` with bundled font: 4,822,805 bytes
- Compressed data increase: 88,228 bytes (about 1.86%)
- Total WebGL output increase: 87,453 bytes
