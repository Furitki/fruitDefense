# Fruit Defense UI font

`NotoSansSC-UI.ttf` is a project-specific regular-weight subset of Google Fonts' Noto Sans SC variable font. Noto Sans SC is distributed under the SIL Open Font License 1.1; the repository copy of that license is `OFL-NotoSansSC.txt`.

Source: https://github.com/google/fonts/tree/main/ofl/notosanssc

The subset is regenerated by `scripts/rebuild-ui-font.ps1` with fontTools 4.63.0 from the visible characters under `Assets/Scripts` and the bundled content JSON, printable ASCII, and the UI symbols `★♥☀♣×·✓…：，。！？（）【】《》`.

Size record for the 2026-07-15 P0 player-flow WebGL build:

- Upstream variable font: 17,772,300 bytes
- Unity font subset after the P0 Lobby/Settlement flow: 253,676 bytes and 392 requested code points
- Final Brotli `WebGL.data.unityweb`: 4,383,934 bytes
- Final versioned WebGL output: 8,067,407 bytes
