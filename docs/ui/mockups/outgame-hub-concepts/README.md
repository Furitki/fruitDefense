# Outgame Hub 概念示意图

本目录保存 Home、Activity、Growth Equipment、Growth Cultivation 四个竖屏页面的评审概念稿。画面按 `402×874` 逻辑竖屏比例设计；生成器输出为约 2× 的预览栅格，实际尺寸记录如下。

这些文件只用于讨论信息层级、页面切换结构、内容密度和「晴空纸张果园」视觉方向。它们不是运行时界面、生产 Sprite、Sprite sheet、九宫格母版或布局几何权威，禁止加入 Unity `Resources`、Theme、ArtSet、Scene、Prefab 或其他 release dependency graph。生产实现仍须使用运行时字体、有限 copy、`PortraitHubLayout`、共享组件和独立的无文字语义资源。

## 生成方式与共同合同

- 工具：Codex 内置 `image_gen`（默认 built-in 模式），未使用 CLI/API 脚本。
- 用例：`ui-mockup`；高保真竖屏手机游戏界面评审稿，不含设备外框。
- 共同提示词摘要：402×874 逻辑比例；晴空蓝边缘、暖白纸面、泥土棕文字/轮廓、叶绿唯一主操作、阳光黄选择强调、克制果红错误；圆润轮廓、浅阴影和少量果园角饰；共享顶栏、page host、固定“主页 / 活动 / 成长”底部导航；颜色之外必须有选中线索；成长页使用较弱的“装备 / 养成”二级切换；保持 4pt 节奏与至少 44pt 操作目标的视觉感；每页只出现一个 page-level Primary；禁止玻璃拟态、科技霓虹、纯黑粗框、厚重倒角、默认 Unity skin、品牌、商标与水印。

## 检查结论与概念稿限制

- 四张图均为独立 PNG，长宽比约为 `402:874`，共享顶栏、底部三项导航、成长二级切换和 Sunny Orchard 视觉语言基本一致。
- 主页首稿曾误把后两关画成锁定；已执行一次定向编辑，最终稿改为三个关卡均可选择，首关保持唯一选中。未继续无界重试。
- 当前可见的指定中文未发现明显错别字；生成字体、字重、字距和排版仍不是运行时权威，生产实现必须改用项目内 Noto Sans SC 与有限 copy catalog。
- `home.png` 中未选关卡下方的浅色叶片圆点可能被误读为进度点；生产实现应使用规范化的 selectable-card 状态 anatomy，不照抄该装饰。
- `activity.png` 的已领取/锁定区域是低层级状态样例，锁定样例没有完整原因文案；生产页面必须为不可用状态提供明确有限原因。
- 生成图中的资源数值、等级、百分比、成本、图标造型和装饰位置都只是构图占位，不构成内容数据、平衡数值、命令或 hit geometry。
- 四张整页生成图不得直接裁切、缩放或贴入运行时。若视觉方向获批，应从共享组件 anatomy 出发，单独生产无文字、可追溯、可验证的语义资源并走现有 ArtSet/Theme 流程。
