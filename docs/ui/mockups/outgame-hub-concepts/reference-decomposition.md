# Outgame Hub 参考图拆解与验收施工尺

本文档是 Worker A/B 实现 `home.png`、`activity.png`、`growth-equipment.png`、`growth-cultivation.png` 的唯一施工尺。

- 所有坐标以左上角为原点，按 `402 × 874` 逻辑设计尺寸标注，并由参考图等比归一化得到。
- 大型面板允许误差为 `±6 px`；交互控件中心允许误差为 `±4 px`，边界允许误差为 `±6 px`；图标光学中心允许误差为 `±3 px`。
- 四张参考图自身存在跨页漂移：顶部栏 Y 约有 `14 px` 偏差、成长页签宽度不一致、底部导航图标 X 约有 `8–12 px` 偏差。生产实现必须使用共享权威布局，不得逐页复刻这些误差。
- 参考图只用于确认视觉层级，不得进入运行时或发布资源图；不得从参考图中裁剪运行时素材。

## 0. 本轮生产裁决

- 主按钮容器恢复最初方形母版的浅青柠叶绿，统一目标色为 `#A0C73D`；纸纹和光影保留该固定 PNG 自身的自然变化。
- 主按钮文字和操作图标统一使用 `#4B2A13` 深泥土棕，不按概念图白字实现。
- `#A0C73D` 与暖泥土棕 `#4B2A13` 的 WCAG 对比度约为 `6.54:1`，暖棕描边满足 `>=4.5:1` 的可辨识门槛。
- 这是本轮实现与验收的强制裁决。不得为追随概念图而改回白字，不得把主按钮叶绿整体压暗，也不得新增页面私有颜色变体。

## 5. 组件与语义素材

### 5.1 必须复用

- 屏幕/安全区布局语义。
- standard surface、raised surface。
- selectable surface。
- `action.primary` 主操作语义。
- status/detail surface。
- selected marker 与状态指示器。
- Lobby 已有的果园主题插画语义。
- Noto 字体资产。
- `PressTracker` 指针状态追踪。
- `PortraitHubLayout` 统一纵向布局权威。

### 5.2 必须新增或扩展

- 连体 Hub 底部导航托盘 anatomy。
- Hub 导航项 normal / selected / pressed anatomy。
- Home、Activity、Growth 三个导航图标。
- Growth 域选中下划线或叶片提示语义。
- 紧凑资源胶囊 anatomy。
- 活动横幅、奖励面板、装备详情、养成详情优先复用现有表面语义，仅在确有缺口时新增槽位。
- 奖励、装备和养成节点图标只有在稳定内容 ID 已确定后才能接入；它们属于内容呈现素材，不属于通用 UI ArtSet。
- 养成树连接线仅为视觉素材，不得成为独立命中几何。

若必须新增 ArtSet 槽位，须同步更新有限资源契约、活动集、母版、导出流程和验证器；不得通过硬编码路径直接加载。

### 5.3 禁止项

- 不得把整页概念图加入 Theme、ArtSet、Resources、Scene 或 Prefab。
- 不得从概念图裁切按钮、卡片、图标、养成树或背景作为运行时资产。
- 不得把中文标题、数值或资源数量烘焙进图片。
- 不得使用 `1280`、`356`、`120`、`80`、`60` 等假数据支撑页面完成度。
- 不得为同一控件维护第二套绘制矩形或命中矩形。

- B 按钮与导航单项必须 `>=18/25`，并通过全部按钮硬门槛。
- C 颜色与材质单项必须 `>=14/20`，并通过全部对比度硬门槛。

- 运行时或发布图依赖整页概念图或其裁剪图。

最终评分必须基于实际 WebGL 运行画面与交互证据，不能只凭代码结构预审判定通过。

11. 主按钮白字对比度问题已由本轮生产裁决解决：容器使用原始方形母版目标色 `#A0C73D`，暖白字面使用暖泥土棕 `#4B2A13` 描边；不再以运行时压暗或脚本调色换取对比度。
